
# REDCap Project: Health Data Collection

## Overview
This REDCap project collects basic health and lifestyle information from participants. All fields are required.

## Instruments & Survey Fields

**Form 1** includes the following fields:

- `record_id` – Unique Record ID (auto-generated)
- `age` – Age of participant
- `gender` – Gender (Male / Female)
- `weight` – Weight (kg)
- `height` – Height (cm)
- `blood_pressure_systolic` – Systolic blood pressure
- `blood_pressure_diastolic` – Diastolic blood pressure
- `resting_heart_rate` – Resting heart rate (bpm)
- `smoker` – Smoking status (Yes / No)

## Notes
- This project is designed for baseline health and lifestyle data collection.
- All fields are required to ensure complete records.
